# PRCP-1010 — Insurance Claim Prediction (InsClaimPred)

Intern-level data science project for predicting insurance claim likelihood and recommending marketing actions.

> **New here?** Start with [`PROJECT_EXPLANATION.md`](./PROJECT_EXPLANATION.md) for a plain-language walkthrough of the problem, dataset, files, results, and recommendations.

This repository was built from the **PRCP-1010-InsClaimPred** capstone brief:

1. **Task 1:** Train a predictive model to help the insurance marketing team identify customers more likely to buy / engage with the product.
2. **Task 2:** Provide suggestions that help the marketing team improve conversion.
3. Deliver a **model comparison report** and a **challenges report** in a single Jupyter notebook.

## Dataset

- Source zip: [PRCP-1010-InsClaimPred.zip](https://d3ilbtxij3aepc.cloudfront.net/projects/CDS-Capstone-Projects/PRCP-1010-InsClaimPred.zip)
- Training file: `train.csv`
- Shape: **595,212 rows × 59 columns**
- Target: binary (`0` / `1`), heavily imbalanced (~3.6% positives)
- Feature names are anonymized for privacy

Download the data:

```bash
python scripts/download_data.py
```

## Modeling approach (intern baseline)

| Step | Approach |
|---|---|
| Missing values | Dataset uses `-1` as a missing sentinel → replace with `NaN`, median impute |
| Split | Stratified train/test split |
| Models | Logistic Regression, Random Forest, Gradient Boosting, XGBoost |
| Imbalance | `class_weight` / `scale_pos_weight` |
| Selection metric | ROC-AUC (+ Normalized Gini, Average Precision) |

Accuracy alone is **not** used as the primary production metric because predicting all negatives would already be ~96% accurate.

## Marketing suggestions (summary)

- Rank customers by predicted probability and prioritize the top decile for outreach.
- Tune decision thresholds to campaign budget (do not default to 0.5).
- Offer safer product tiers to higher-risk scored segments; conversion offers to safer segments.
- Validate with A/B tests (model-targeted vs random outreach).
- Retrain periodically as customer and claim patterns drift.

## Challenges & techniques

| Challenge | Technique |
|---|---|
| Class imbalance | Weighted models + ranking metrics |
| `-1` missing encoding | Explicit NaN conversion + imputation |
| Anonymized features | Focus on model quality and importance proxies |
| Large dataset | Stratified sampling for iteration; full-data option available |
